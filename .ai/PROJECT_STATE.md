# Project State

## What This Project Is

**Product:** Game Agent Network (GAN)
**Purpose:** A local-first game-production orchestration system that turns Director intent into typed tasks, specialist work, evidence, and auditable project history.
**Users:** A game Director or small production team operating local project repositories.
**Stage:** Alpha; Phases 7–12 are implemented, with the Windows desktop package ready for Director review.

## Current Status

**Overall health:** yellow

### Working

- Local daemon, Next.js Studio, project switching/import/removal, event replay, SQLite projections, reconciliation, GM planning, workers, QA, provider caps, model routing, and five production-domain audits.
- Knowledge Fabric contracts, immutable global pack registry, FTS retrieval, four knowledge planes, bounded task packets, source provenance/freshness, project isolation, Pack Builder/governance/auditions, research, observations, lesson review/promotion, and visible maintenance state.
- Four compact built-in packs: `game-ux-core`, `game-engineering-core`, `game-qa-core`, and `godot-ui-engineering`.
- Recruiter diagnoses agent, pack, stale-knowledge, tool, model, and repeated-performance gaps before proposing a new agent.
- Electron owns the packaged Studio and daemon child processes without changing daemon authority. A separate headless daemon distribution preserves CLI and service operation.
- Full repository acceptance is `pnpm check`; the 2026-09-11 Phase 12 checkpoint passed 190 daemon tests, 60 protocol tests, builds, and Playwright smoke.

### Broken / Incomplete

- The Knowledge Fabric addendum is not complete. Ten of its fourteen initial packs remain missing, and the existing four seed packs do not yet have a completed professional benchmark program.
- Broad Lead Bench qualification, exact worker model/tool composition receipts, failure postmortems, importable pack CLI, richer maintenance policy, and the full addendum acceptance/portfolio suite remain.
- The first desktop release is Windows x64 only and is not yet code-signed by a trusted publisher.

### Abandoned / Deprecated

- None. SQLite and search indexes are derived and may be rebuilt; they are not canonical stores.
