## Foundation consequences

1. Use a single versioned contract source and generated TypeScript/JSON Schema.
2. Separate global capability definitions from project assignments and threads.
3. Keep knowledge provenance, QA evidence, review decisions and presentation apart.
4. Encode authority, evidence, reconciliation and spending rules as pure tests.
5. Defer graph implementation, backend state, advisor sessions and UI navigation
   until their corresponding phases. Phase 0 contains no fabricated production UI.
