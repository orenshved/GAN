Pure guards are foundation specifications. Future command handlers must call
them with trusted records; they do not establish an operating orchestration system.

Completion requires latest authoritative evaluations for all required gates or
explicit scoped human waiver events. Phase 7 derives this result from canonical
project history and exposes the precise gate/evidence rationale in Studio.

Recruitment does not relax QA admission. Probationary agents have advisory QA
authority and require independent verification; their pass cannot satisfy a
required gate.

Model routing does not relax provider admission. A local route requires the current
model digest, available-memory fit and a passing task-specific benchmark. Every
paid invocation enters the Phase 9 gateway with a known upper-bound cost, current
provider-side proof and an atomic budget reservation. A request at 100 cents or
more also needs exact, unexpired human approval. Missing model, account, adapter,
credential, cap or cost state fails closed.

Production-domain scans never execute discovered project code. Their eligible
passes establish only that matching files were found, read, structurally validated
and content-addressed. Gameplay feel, level readability, art quality, audio mix,
narrative continuity and fun remain unsupported until stronger measured,
comparative or human evidence is recorded.

Project onboarding prefers specialist discovery over user questioning. Unknowns
that do not block current work remain durable Project Intelligence; only
irreducible, materially blocking questions interrupt the Director.

Knowledge routing does not merge epistemic planes. Professional knowledge, project
facts and inferences, external facts, observations, heuristics, hypotheses, human
judgment and measured evidence retain distinct labels. The global FTS index is
rebuildable from curated pack manifests and never indexes project material.
